Alternativas

  • Windows, macOS, Android y ChromeOS: abre esta página en Chrome, Edge u Opera.
  • Linux: usa la AppImage, o Chrome con chrome://flags/#enable-experimental-web-platform-features activado.
  • iPhone y iPad: ningún navegador de iOS tiene Web Bluetooth salvo Bluefy (gratis en la App Store); abre esta página en él.
  • Línea de comandos: print.py del repositorio funciona en Linux, macOS y Windows.
